Conclusion & Future Work

Conclusion

This project explored how procedural terrain can be generated using Perlin noise and how such a system can be optimized for real-time use in Unity.

Perlin noise proved to be a strong foundation for terrain generation. By adjusting parameters such as scale, octaves, persistence, and lacunarity, it is possible to control both the structure and the level of detail in the generated terrain.

However, a single noise layer was not sufficient to create varied and believable environments. By combining multiple maps, specifically height and temperature, the system was extended into a biome-based approach that produces more diverse and realistic results.

A major limitation of the system was performance. As the generation pipeline became more complex, issues such as lag spikes during object instantiation became visible. This showed that procedural generation is not only a design problem, but also a performance problem.

By applying techniques such as chunk-based generation, level of detail, smarter object placement, and multithreading, the system became more suitable for real-time use.

Future Work

One important extension would be the addition of a moisture map. Combined with height and temperature, this would allow for a more advanced biome system with greater variation.

Another improvement would be biome blending. The current system uses hard thresholds, which results in harsh visible transitions. Blending between biome types would create smoother and more natural transitions.

Performance could also be improved further by using techniques such as GPU-based generation or compute shaders.

Additionally, rendering optimizations such as GPU instancing or billboards could reduce the cost of large numbers of objects.
