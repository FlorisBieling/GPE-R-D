Step 3: From Noise to Terrain Shapes

Intro

Up to this point, the generated values have only been shown as grayscale. While this is useful for understanding the structure, the data itself does not yet represent anything meaningful.

By interpreting these values as height, the same data can now be used to define terrain shapes.

This means that low values can represent water, slightly higher values can represent beaches, and high values can represent mountains. Instead of looking at the map as black and white pixels, it now becomes possible to read it as a simple terrain layout.

How Height Thresholds Work

A noise map is basically a grid of values between 0 and 1. On their own, these values do not mean anything yet. A threshold is a chosen boundary that decides how a value should be interpreted.

For example:

- values below 0.35 can be water
- values between 0.35 and 0.42 can be beach
- values between 0.42 and 0.70 can be grass
- values above 0.70 can be mountain

This makes it possible to turn one noise map into different terrain types. The map is still generated from the same noise system, but it becomes much easier to understand visually.

How This Works in Unity

In Unity, this is often done by checking the height value and assigning a color or terrain type based on it. The following example shows the basic idea. 

for (int y = 0; y < mapHeight; y++)
{
    for (int x = 0; x < mapWidth; x++)
    {
        float currentHeight = noiseMap[x, y];

        if (currentHeight < 0.35f)
        {
            colorMap[y * mapWidth + x] = Color.blue;
        }
        else if (currentHeight < 0.42f)
        {
            colorMap[y * mapWidth + x] = new Color(0.9f, 0.85f, 0.6f);
        }
        else if (currentHeight < 0.70f)
        {
            colorMap[y * mapWidth + x] = Color.green;
        }
        else
        {
            colorMap[y * mapWidth + x] = Color.gray;
        }
    }
}

What This Code Does

The code loops over every position in the map and checks the height value at that position. Based on the value, a terrain category is chosen.

This means the map is no longer only showing intensity, but is now divided into readable terrain regions. Low areas become water, medium areas become land, and high areas become mountains.

The thresholds can be adjusted to completely change the result. A lower water threshold creates less ocean, while a higher one creates more. Because of this, thresholds are a simple but powerful way to shape the world.

Why This Is Useful

A grayscale noise map is useful for understanding the structure of the data, but it is still quite abstract. By assigning terrain categories to different value ranges, the same data becomes much easier to interpret.

This is useful because one noise map can already form the basis of a simple world. Even without extra systems like temperature or moisture, it becomes possible to separate water, coast, land, and mountain areas.

In the next step, this idea can be expanded further by combining multiple maps, such as height and temperature, to create more detailed biome systems.
