Implementation guide: adding the current system to Unity

Practical setup

The download is now one complete package containing the refactored terrain scripts, custom URP shader, material snapshot, texture-assignment utility and camera controls. The raw Asset Store textures are intentionally not included.

Download ProceduralTerrainCompletePackage.zip

One zip replaces the previous list of separate script downloads.

Dependency: import Yughues Free Ground Materials from the Unity Asset Store before running the assignment tool. The package does not redistribute the original texture files.

1. Copy the package into Unity

  1. Make a Git commit or project backup first.
  2. Extract the zip outside the Unity project.
  3. Copy the contents of Assets/Perlin/ into your project's Assets/Perlin/ folder.
  4. Do not blindly overwrite a working scene or material. Compare them first when your project already contains references.
  5. Allow Unity to recompile and resolve the shader before continuing.
Material portability note: Unity materials use asset GUIDs internally. The included MaterialProceduralTerrain.mat is useful as a project snapshot, but shader and texture references can be lost when copied without the original .meta files. Reassign the shader and run the editor utility when necessary.

2. Use the recommended folder structure

The current screenshots are understandable, but the improved package moves the editor-only assignment script out of Materials and renames the camera files to match their MonoBehaviour classes.

3. Configure the shader material

  1. Create or select MaterialProceduralTerrain.
  2. Assign Custom/ProceduralBiomeTexturesURP as its shader.
  3. Import the Yughues texture package.
  4. Select the material in the Project window.
  5. Run Tools → Procedural Terrain → Assign Final YFGM Textures.
  6. Check the Console for missing texture names and inspect the seven texture groups.

4. Create the scene objects

  1. Create an empty GameObject named TerrainSystem.
  2. Add MapGenerator and EndlessTerrain.
  3. Assign the player or camera Transform to EndlessTerrain.viewer.
  4. Assign the procedural terrain material to EndlessTerrain.mapMaterial.
  5. Create an optional preview object with a Renderer, MeshFilter, MeshRenderer and MapDisplay.
  6. Add TopDownCameraMovement and CameraHeightControl to the viewer when the research scene needs free camera movement.

5. Configure noise and mesh settings

SettingPurposeWhy this setting is useful
Normalize ModeMaps accumulated noise into a usable range.Global normalization keeps independently generated chunks comparable; local normalization remains useful when inspecting a single preview.
Noise ScaleControls the size of terrain features.It provides a direct artistic control over whether the world contains broad regions or smaller, busier features.
OctavesAdds multiple levels of detail.Additional octaves add progressively smaller detail while preserving the large base forms.
PersistenceControls the strength of later octaves.It lets the designer decide how strongly the smaller octave details remain visible.
LacunarityControls frequency growth.It controls how quickly each octave moves from broad variation to fine detail.
Mesh Height MultiplierScales normalized height into Unity units.It converts the normalized map into a world scale that matches the camera and intended landscape size.
Mesh Height CurveRemaps height non-linearly.It shapes the height distribution without changing the noise source, making flat lowlands and steeper peaks easy to author.

6. Configure climate and biome rules

Use separate scale multipliers and offsets for temperature and moisture. Add explicit biome texture types and clear min/max ranges for height, temperature and moisture. Priority is useful for intentional overlap, such as a narrow beach taking precedence over a broad plains range. The closest-range fallback then keeps every generated coordinate valid.

7. Configure control-map blending and snow

Start with a clear base transition and then add softness, boundary noise and patch variation step by step. For snow, first choose the start and full-coverage heights, then use line variation and holes to make the border more natural.

8. Configure decorations and LOD

Begin with a readable sample interval and a small set of prefabs, then increase density while observing the result. Decorations are shown at LOD 0 so object detail is concentrated near the viewer, where it contributes most.

9. Test in this order

  1. Compile scripts and verify the editor utility is inside an Editor folder.
  2. Verify the material uses the custom URP shader and has the expected texture sets.
  3. Preview height, temperature and moisture separately.
  4. Preview biome colors and inspect gaps or accidental overlaps.
  5. Preview Control Map A and B.
  6. Preview the final mesh and material, especially steep slopes and chunk borders.
  7. Enter Play Mode and test viewer movement, chunk loading and LOD switching.
  8. Enable decorations last and profile frame time, memory and object count.
