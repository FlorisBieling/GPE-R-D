Step 4: Combining Height and Temperature

In the previous step, the world was divided into simple terrain shapes using only height values. That already made the map easier to read, but it also had a limitation: areas with the same height would always be treated the same way.

In the Unity project, this is solved by generating not only a height map, but also a temperature map. These two maps are then combined to decide which biome should appear at each position.

How This Works in the Project

The height map determines the overall structure of the world. The temperature map adds another layer of information. This means that two areas with the same height can still become different biomes if their temperature is different.

For example, high terrain can become a cold snowy biome or a warmer rocky biome, while medium-height land can become greener or drier depending on the temperature.

How This Works in Unity

In the project, both maps are generated separately. The temperature map uses the same noise system as the height map, but with a different seed and a much larger scale. 

float[,] heightMap = Noise.GenerateNoiseMap(
    mapChunkSize,
    mapChunkSize,
    seed,
    noiseScale,
    octaves,
    persistance,
    lacunarity,
    centre + offset,
    normalizeMode
);

float[,] temperatureMap = Noise.GenerateNoiseMap(
    mapChunkSize,
    mapChunkSize,
    seed + 2,
    noiseScale * 5f,
    octaves,
    persistance,
    lacunarity,
    centre + offset,
    normalizeMode
);

After that, both values are read at the same position and passed into the biome system. 

float currentHeight = heightMap[x, y];
float currentTemperature = temperatureMap[x, y];
colorMap[y * mapChunkSize + x] = GetColor(currentHeight, currentTemperature);

What This Means

Height and temperature each describe a different property of the world. Height controls where terrain is low or high, while temperature changes what kind of biome fits that area.

This makes the world more varied and believable, because the final biome is no longer based on just one value.

Why This Is Useful

A single map can create the basic structure of a world, but combining multiple maps makes it possible to create more interesting regions. Height gives the world its shape, while temperature adds variation within that shape.

This is an important step, because it moves the project away from simple terrain categories and towards a real biome system.

In the next step, this data can be used as the basis for actual world generation in Unity, where the generated maps are no longer only visualized, but also used to build the terrain itself.
