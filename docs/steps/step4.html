Step 4: Biomes Using Multiple Map Layers

In the previous step, one noise map was used to divide the world into simple terrain shapes. This already made the map easier to understand, but it still had a limitation: every area was based on height alone.

In reality, biomes are usually not only determined by height. A mountain can be snowy or rocky, land can be grassy or dry, and low areas can be cold or warm. To make the world more varied, multiple map layers can be combined.

Why One Map Is Not Enough

A single height map can show where the world is low or high, but it cannot explain what kind of environment that area should have. Two areas with the same height can still look very different if one is cold and the other is warm.

That is why a second map can be added. In this step, a temperature map is combined with the height map. The height map still controls the structure of the world, while the temperature map helps decide what biome should appear there.

How Multiple Maps Create Biomes

The height map and temperature map are both generated using noise. They are created separately, and each one describes a different property of the world.

For example:

- low height + low temperature can become cold ocean
- low height + high temperature can become warm ocean
- medium height + low temperature can become tundra
- medium height + high temperature can become desert
- high height + low temperature can become snow
- high height + medium temperature can become mountain

This means the final biome is no longer based on one value, but on the combination of multiple values.

How This Works in Unity

In Unity, this can be done by reading both maps at the same position and selecting a biome based on the combination of those values. 

float currentHeight = heightMap[x, y];
float currentTemperature = temperatureMap[x, y];

if (currentHeight < 0.35f)
{
    if (currentTemperature < 0.4f)
    {
        colorMap[index] = coldOceanColor;
    }
    else
    {
        colorMap[index] = warmOceanColor;
    }
}
else if (currentHeight < 0.7f)
{
    if (currentTemperature < 0.3f)
    {
        colorMap[index] = tundraColor;
    }
    else if (currentTemperature < 0.65f)
    {
        colorMap[index] = grassColor;
    }
    else
    {
        colorMap[index] = desertColor;
    }
}
else
{
    if (currentTemperature < 0.45f)
    {
        colorMap[index] = snowColor;
    }
    else
    {
        colorMap[index] = mountainColor;
    }
}

What This Code Does

The code checks both the height and temperature at the same position. Height is used first to decide the broad terrain type, and temperature is then used to decide which biome fits within that terrain.

This makes the world more believable. Instead of every medium-height area looking the same, the same height can now become grassland, tundra, or desert depending on temperature.

Why This Is Useful

Combining multiple maps makes the world much more flexible. Height still gives the overall structure, but the second map allows variation within that structure.

This creates more interesting and believable results, because areas are no longer defined by just one property. The same terrain height can now lead to different biomes depending on temperature.

In the next step, these maps can be used as the basis for actual world generation in Unity, where the data is no longer only visualized but also applied to terrain, tiles, or objects.
