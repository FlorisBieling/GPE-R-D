Step 2: Fractal noise, octaves and normalization

More structure

One noise layer creates broad smooth shapes. The current generator combines several layers so large landforms and smaller details can exist in the same map.

Octaves

The number of noise layers that are added together.

Persistence

How much amplitude each following layer keeps.

Lacunarity

How quickly each following layer increases in frequency.

Normalization

Converts the accumulated result into a usable map range.

Current implementation

for (int i = 0; i < octaves; i++)
{
    float perlinValue = Mathf.PerlinNoise(sampleX, sampleY) * 2f - 1f;
    noiseHeight += perlinValue * amplitude;

    amplitude *= persistance;
    frequency *= lacunarity;
}

The first octave defines the largest shapes. Later octaves sample at a higher frequency and normally use a smaller amplitude. This is why increasing octaves adds detail without completely replacing the base terrain.

Local and global normalization

Local normalization stretches each generated chunk between its own minimum and maximum. It is useful for previews, but neighbouring chunks can interpret identical raw values differently. Global normalization uses a theoretical maximum amplitude and is therefore more suitable when continuity between independently generated chunks matters.

Why layered Perlin noise was chosen

Compared with one noise layer

It combines large shapes and fine detail

The first octave defines the landmass while later octaves add smaller structure. This gives a richer result without replacing the original generation method.

Compared with mixing several unrelated algorithms

The controls remain consistent

Every layer uses the same sampling model, so scale, persistence and lacunarity remain understandable and can be tuned together in the Inspector.

Compared with adding geometry detail later

The detail already exists in the source data

Biome rules, mesh generation and previews all read the same detailed map, which keeps the pipeline coherent.

Tuning consideration

More detail should remain purposeful

Very high octave counts or persistence values can add work without improving the visible result. The chosen settings should therefore be judged at the actual mesh resolution and LOD distances.
