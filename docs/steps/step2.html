Step 2: More Noise Parameters

Goal of This Step

The first step introduced Perlin noise as a structured alternative to pure randomness. While that already produced smoother and more usable data, a single layer of noise was still limited. The resulting map could show broad variation, but it lacked the complexity needed for more believable terrain.

This step continues answering sub question 1 by focusing on how the main Perlin noise parameters influence the generated result. In particular, it explores how octaves, persistence, and lacunarity change the balance between large shapes and small details.

Why a Single Noise Layer Was Not Enough

A single layer of Perlin noise can create smooth variation, but terrain in games usually needs more than one level of structure. Real landscapes are not made up of only broad hills or only tiny details. They contain large overall shapes, medium variation, and smaller rough features at the same time.

Because of that, using only one layer of noise made the terrain feel too simple. It could provide a base pattern, but not enough richness to be a strong foundation for a larger terrain system.

The solution is to combine multiple layers of noise. Instead of generating one pattern, the system generates several patterns at different scales and strengths, and blends them together into one final result.

Why This Method Was Chosen

This layered approach was chosen because it keeps the strengths of Perlin noise while making the result much more flexible. It allows the system to preserve large terrain forms while also adding smaller features on top.

Other methods could also increase complexity, but this approach fits well with the rest of the project because it stays within the same procedural model. Instead of switching to a completely different generation method, the original Perlin noise system is extended in a controlled way.

What These Parameters Do

Octaves

Octaves determine how many layers of noise are combined. The first octave creates the broadest shapes, while each additional octave adds a new layer of smaller detail. Increasing the number of octaves therefore makes the terrain richer and more varied.

In practice, this means that low octave values produce smoother and simpler maps, while higher octave values create terrain with more visible structure.

Persistence

Persistence controls how much influence each new octave has compared to the previous one. If persistence is low, the higher octaves contribute only a small amount, so the large shapes remain dominant. If persistence is high, the smaller details stay much more visible.

This means persistence directly affects how rough or smooth the final terrain feels.

Lacunarity

Lacunarity controls how quickly the frequency increases for each additional octave. In other words, it determines how much smaller and more compressed each new layer becomes.

A lower lacunarity keeps the layers more similar, while a higher lacunarity creates a stronger contrast between broad shapes and fine details.

How These Parameters Work Together

These parameters are closely connected. Octaves determine how many layers are added, persistence determines how visible those extra layers remain, and lacunarity determines how different in scale those layers become.

Together, they allow one procedural system to produce very different terrain styles. The result can range from smooth rolling landscapes to rougher and more broken terrain, depending on how the parameters are combined.

This is important because it shows that Perlin noise is not only useful as a single function, but also as a flexible system that can be tuned for different kinds of worlds.

How This Works in Unity

In Unity, this is done by looping through several octaves of noise for every position in the map. Each octave samples the noise function again, but with a different frequency and amplitude. 

amplitude = 1;
frequency = 1;
float noiseHeight = 0;

for (int i = 0; i < octaves; i++)
{
    float sampleX = (x - halfWidth + octaveOffsets[i].x) / scale * frequency;
    float sampleY = (y - halfHeight + octaveOffsets[i].y) / scale * frequency;

    float perlinValue = Mathf.PerlinNoise(sampleX, sampleY) * 2 - 1;
    noiseHeight += perlinValue * amplitude;

    amplitude *= persistance;
    frequency *= lacunarity;
}

What This Code Does

The loop runs once for every octave. Each time, the system samples a new layer of Perlin noise and adds it to the total height value. At the start, both amplitude and frequency are set to 1. After each octave, amplitude is multiplied by persistence and frequency is multiplied by lacunarity.

This means the first octave has the strongest influence and represents the broad shape of the terrain, while later octaves gradually add smaller details. Because of this, the final value is no longer based on one smooth pattern, but on a combination of multiple layers.

This directly answers the first sub question: these parameters do not just exist as extra settings, but fundamentally control how much detail, roughness, and variation the terrain will contain.

What This Step Adds to the System

This step expands the procedural system from a simple proof of concept into something much more suitable for terrain generation. Instead of producing only one smooth pattern, the system can now represent both large structures and smaller variation within the same map.

That makes it a much stronger base for the next step, where the noise values are no longer shown only as grayscale, but are interpreted as meaningful terrain categories such as water, land, and mountains.
