Step 2: More Noise Parameters

Intro

In the previous step, the noise map was generated using only the scale value. While this created a basic terrain shape, the result was still quite simple and lacked detail.

To make the terrain more interesting, additional parameters can be used. These parameters allow multiple layers of noise to be combined into a single result, creating both large shapes and smaller details.

The main parameters that make the noise more complex are octaves, persistence, and lacunarity. These allow multiple layers of noise to be combined into one final result.

What These Parameters Do

Let's start with a quick overview of what these parameters do:

Octaves

Octaves determine how many of these layers are used. Each octave adds a new layer of noise on top of the previous one. The first octave creates the large, overall shape of the terrain, while the next octaves add smaller and smaller details. This means that increasing the number of octaves adds more detail to the terrain.

You can think of this like drawing: first you sketch the big shapes, and then you add a new layer of details on top, and again, as many times as you want.

Persistence

Persistence controls how strong each new layer is compared to the previous one.

If persistence is low, each new layer becomes much weaker,
so the terrain is mostly defined by the large shapes.
If persistence is high, the smaller details remain strong,
making the terrain look more rough and detailed.

Lacunarity

Lacunarity controls how quickly the detail becomes smaller for each new layer.

If lacunarity is low, the layers are more similar in size,
which keeps the terrain smooth.
If lacunarity is high, each new layer becomes much smaller,
which creates sharper and more detailed patterns.


These three parameters always work together:

Octaves decide how many layers you add.
Persistence decides how visible each layer is.
Lacunarity decides how different each layer looks.

Because of this combination, the terrain is no longer just one smooth pattern, but a mix of large shapes and small details, as you will see in the demo after the code is shown and explained.

How This Works in Unity

In Unity, this is done by looping through multiple layers of Perlin noise. Each layer has its own amplitude and frequency. 

amplitude = 1;
frequency = 1;
float noiseHeight = 0;

for (int i = 0; i < octaves; i++)
{
    float sampleX = (x - halfWidth + octaveOffsets[i].x) / scale * frequency;
    float sampleY = (y - halfHeight + octaveOffsets[i].y) / scale * frequency;

    float perlinValue = Mathf.PerlinNoise(sampleX, sampleY) * 2 - 1;
    noiseHeight += perlinValue * amplitude;

    amplitude *= persistance;
    frequency *= lacunarity;
}

What This Code Does

The loop runs once for each octave. Every time it runs, a new layer of noise is sampled and added to the total height.

At the start, the amplitude and frequency are both set to 1. After each octave, the amplitude is multiplied by persistence and the frequency is multiplied by lacunarity.

This means the first layer gives the broad shape of the terrain, while later layers add smaller and smaller details on top of it.

So instead of one single smooth pattern, the final map becomes a combination of large forms and fine detail.

Why This Is Useful

Using only one layer of noise often creates terrain that looks too simple and unrealistic. By combining multiple layers, it becomes possible to create terrain that has both large overall shapes and smaller local variation.

This is useful because terrain in games usually needs different levels of detail. Large hills, smaller bumps, and rougher local changes can all be created from the same system.
