Step 1: Perlin noise as continuous terrain data

Foundation

The first requirement is not a mountain or a biome. It is a stable field of values in which neighbouring coordinates change gradually. Unity's Mathf.PerlinNoise provides that foundation.

Why coherent noise is used

Independent random values create disconnected spikes. Coherent noise creates related values across space, so the map can be interpreted as continuous height. A seed and coordinate offset make the result repeatable: the same inputs produce the same world.

Core Unity logic

float sampleX = (x - halfWidth + octaveOffsets[i].x) / scale * frequency;
float sampleY = (y - halfHeight + octaveOffsets[i].y) / scale * frequency;

float perlinValue = Mathf.PerlinNoise(sampleX, sampleY) * 2f - 1f;
noiseHeight += perlinValue * amplitude;

The coordinates are divided by scale. A small scale moves through noise space quickly and produces compact features. A large scale stretches the pattern into broad regions. The result is converted from approximately 0–1 to -1–1 before the octave amplitude is applied.

Interactive basic noise demo

Design choice

Perlin noise is a source, not a biome system. The noise only supplies continuous values. Meaning is added later by normalization, climate maps, biome rules, control maps and the shader.

Why Perlin noise was chosen

Compared with random values

It creates continuous terrain

Independent random values would create disconnected spikes. Perlin noise keeps neighbouring samples related, which is exactly what a height field needs.

Compared with a hand-authored heightmap

It supports repeatable endless generation

A fixed seed and world coordinates reproduce the same result anywhere, so chunks can be generated when needed without storing one enormous image.

Compared with a physical terrain simulation

It is lightweight and easy to control

Erosion or geological simulation can create more realistic formations, but Perlin noise is faster, simpler to expose in the Inspector and sufficient for the stylised world this project needs.
