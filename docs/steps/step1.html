The Unity implementation for this step is split into three scripts. Each script has a clear responsibility: generating the noise values, controlling when the map is created, and displaying the result visually.

Noise.cs
This script generates the actual Perlin noise map. It creates a 2D array of float values and fills it by sampling Unity’s built-in Mathf.PerlinNoise function. Each position in the grid is converted into a noise value between 0 and 1. The scale determines how zoomed in or stretched the noise pattern is. 

using UnityEngine;

public static class Noise
{
    public static float[,] GenerateNoiseMap(int mapWidth, int mapHeight, float scale)
    {
        float[,] noiseMap = new float[mapWidth, mapHeight];

        if (scale <= 0)
        {
            scale = 0.0001f;
        }

        for (int y = 0; y < mapHeight; y++)
        {
            for (int x = 0; x < mapWidth; x++)
            {
                float sampleX = x / scale;
                float sampleY = y / scale;

                float perlinValue = Mathf.PerlinNoise(sampleX, sampleY);
                noiseMap[x, y] = perlinValue;
            }
        }

        return noiseMap;
    }
}

The nested loops go over every coordinate in the map. For each position, the x and y values are divided by the scale to control the frequency of the noise. A smaller scale results in more variation (more detail), while a larger scale produces smoother, more gradual transitions.

MapGenerator.cs
This script controls when a new map is generated. It calls the noise function and passes the result to the display script. This keeps the logic separated: one script generates data, another handles when it happens. 

using UnityEngine;

public class MapGenerator : MonoBehaviour
{
    public int mapWidth;
    public int mapHeight;
    public float noiseScale;

    public bool autoUpdate;

    public void GenerateMap()
    {
        float[,] noiseMap = Noise.GenerateNoiseMap(mapWidth, mapHeight, noiseScale);

        MapDisplay display = FindObjectOfType();
        display.DrawNoiseMap(noiseMap);
    }
}

This script acts as the central point of control. It gathers the settings (width, height, scale), generates the noise map, and forwards the result. By separating this from the noise calculation, the system stays flexible and easier to expand later.

MapDisplay.cs
This script converts the noise values into a visible texture. Each value is mapped to a grayscale color, where 0 is black and 1 is white. The result is then applied to a material so it can be displayed in the scene. 

using UnityEngine;

public class MapDisplay : MonoBehaviour
{
    public Renderer textureRenderer;

    public void DrawNoiseMap(float[,] noiseMap)
    {
        int width = noiseMap.GetLength(0);
        int height = noiseMap.GetLength(1);

        Texture2D texture = new Texture2D(width, height);

        Color[] colorMap = new Color[width * height];

        for (int y = 0; y < height; y++)
        {
            for (int x = 0; x < width; x++)
            {
                colorMap[y * width + x] = Color.Lerp(Color.black, Color.white, noiseMap[x, y]);
            }
        }

        texture.SetPixels(colorMap);
        texture.Apply();

        textureRenderer.sharedMaterial.mainTexture = texture;
        textureRenderer.transform.localScale = new Vector3(width, 1, height);
    }
}

The noise values are translated into colors using Color.Lerp. This linearly interpolates between black and white based on the noise value. After that, the texture is applied to a renderer and scaled to match the dimensions of the noise map.
