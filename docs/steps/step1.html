Step 1: Perlin Noise

Intro

The starting point of this project is generating a noise map using Perlin noise. Instead of assigning completely random values, Perlin noise creates smooth transitions between values. This makes it useful for things like terrain generation, where abrupt changes would look unnatural.

In this project, each position on the map gets a value that represents height. These values are later used to create terrains and biomes, and could be used for other world features in the future.

How Perlin Noise Works

Perlin noise works by dividing space into a grid. Each grid point influences the surrounding area. Instead of random values, nearby positions produce similar results, which creates smooth patterns.

For every position:

1. The surrounding grid points are determined
2. A value is calculated based on distance and direction
3. The results are blended together smoothly

This results in a continuous surface instead of random noise.

Noise Generation in Unity

Below is the actual implementation used in Unity to generate the noise map. It loops over every position and calculates a height value using multiple layers (octaves) of Perlin noise. 

public static float[,] GenerateNoiseMap(int mapWidth, int mapHeight, int seed, float scale, int octaves, float persistance, float lacunarity, Vector2 offset)
{
    float[,] noiseMap = new float[mapWidth, mapHeight];

    System.Random prng = new System.Random(seed);
    Vector2[] octaveOffsets = new Vector2[octaves];

    float amplitude = 1;
    float frequency = 1;

    for (int i = 0; i < octaves; i++)
    {
        float offsetX = prng.Next(-100000, 100000) + offset.x;
        float offsetY = prng.Next(-100000, 100000) - offset.y;
        octaveOffsets[i] = new Vector2(offsetX, offsetY);

        amplitude *= persistance;
    }

    if (scale <= 0)
    {
        scale = 0.0001f;
    }

    float halfWidth = mapWidth / 2f;
    float halfHeight = mapHeight / 2f;

    for (int y = 0; y < mapHeight; y++)
    {
        for (int x = 0; x < mapWidth; x++)
        {
            amplitude = 1;
            frequency = 1;
            float noiseHeight = 0;

            for (int i = 0; i < octaves; i++)
            {
                float sampleX = (x - halfWidth + octaveOffsets[i].x) / scale * frequency;
                float sampleY = (y - halfHeight + octaveOffsets[i].y) / scale * frequency;

                float perlinValue = Mathf.PerlinNoise(sampleX, sampleY) * 2 - 1;
                noiseHeight += perlinValue * amplitude;

                amplitude *= persistance;
                frequency *= lacunarity;
            }

            noiseMap[x, y] = noiseHeight;
        }
    }

    return noiseMap;
}

What This Code Does

Now this is a lot code code. For now, let's focus on the basics of how the noise map is generated.

The code loops over every position in the map and calculates a noise value. Each position is converted into noise coordinates using the scale value.

The important part is:

float sampleX = (x - halfWidth) / scale;
float sampleY = (y - halfHeight) / scale;

The scale determines how detailed the noise is:

- Small scale = more detail
- Large scale = smoother terrain

There are a lot of other things going on in the code, such as octaves, persistence, and lacunarity, which add more layers of noise to create more complex terrain. This will be explained further in the next step.

Why This Is Useful

Perlin noise creates structured randomness, which makes it ideal for procedural generation. It is commonly used for:

- Terrain height maps
- Biome generation
- Clouds and fog
- Procedural textures

To make this more useful, additional parameters can be introduced to increase complexity.
